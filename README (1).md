# LUMORA HOTEL

Website reservasi dan simulasi check-in hotel sederhana yang dibuat sebagai proyek pembelajaran **kelas XI Rekayasa Perangkat Lunak (RPL)**.

LUMORA HOTEL menggunakan desain minimalis dan elegan dengan kombinasi warna krem, putih, cokelat, dan emas. Website ini dibuat menggunakan HTML, CSS, dan JavaScript tanpa backend atau database.

## ✨ Fitur Website

- **Home** — halaman utama yang memperkenalkan LUMORA HOTEL.
- **About** — menampilkan informasi singkat tentang hotel.
- **Rooms** — menampilkan pilihan kamar beserta informasi dan harga contoh.
- **Booking** — formulir reservasi dengan perhitungan total harga berdasarkan jumlah malam.
- **Check-in** — simulasi check-in menggunakan kode booking dan nama pemesan.
- **Contact** — menampilkan informasi kontak dan formulir pesan sederhana.
- **Responsive Design** — tampilan menyesuaikan ukuran layar komputer maupun ponsel.

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| HTML | Membuat struktur dan isi halaman website. |
| CSS | Mengatur warna, tata letak, font, dan tampilan responsif. |
| JavaScript | Menjalankan interaksi, validasi formulir, dan perhitungan harga. |
| LocalStorage | Menyimpan data booking sementara di browser. |

## 🚀 Cara Menjalankan Website

1. Ekstrak file ZIP proyek LUMORA HOTEL.
2. Buka folder `Lumora-Hotel` menggunakan Visual Studio Code.
3. Buka file `index.html` menggunakan browser.
4. Jika menggunakan Visual Studio Code, kamu juga dapat menjalankannya dengan ekstensi **Live Server**.
5. Pastikan koneksi internet aktif jika ingin memuat gambar dan font dari layanan eksternal.

## 📝 Cara Mencoba Fitur Booking dan Check-in

1. Buka halaman **Rooms** untuk melihat pilihan kamar.
2. Masuk ke halaman **Booking** dan isi formulir reservasi.
3. Periksa perhitungan total harga, lalu kirim formulir.
4. Simpan atau salin kode booking yang ditampilkan.
5. Buka halaman **Check-in**.
6. Masukkan kode booking dan nama pemesan yang sama dengan data reservasi.
7. Kirim formulir untuk melihat hasil simulasi check-in.

## 🎨 Mengubah Konten Website

- Untuk mengganti teks dan informasi hotel, edit file HTML yang sesuai.
- Untuk mengubah warna, font, ukuran, atau tata letak, edit `css/style.css`.
- Untuk mengubah fungsi booking dan check-in, edit `js/script.js`.
- Harga kamar dan informasi contoh lainnya dapat disesuaikan dengan kebutuhan proyek.

## ⚠️ Batasan Proyek

- Website ini merupakan **proyek frontend**, bukan sistem reservasi hotel sungguhan.
- Data reservasi disimpan menggunakan LocalStorage pada browser yang digunakan.
- Data tidak tersimpan di server dan tidak otomatis tersedia di perangkat atau browser lain.
- Formulir kontak hanya simulasi dan belum mengirim pesan ke email atau server.
- Belum tersedia login admin, pembayaran online, maupun database.
- Informasi hotel, harga, kontak, dan gambar merupakan contoh yang dapat diganti.

## 👨‍💻 Tujuan Proyek

Proyek ini dibuat untuk mempraktikkan dasar pengembangan website menggunakan HTML, CSS, dan JavaScript, termasuk pembuatan beberapa halaman, desain responsif, validasi formulir, perhitungan sederhana, serta penyimpanan data menggunakan LocalStorage.
